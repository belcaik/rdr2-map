# RDR2 frontend

React/TypeScript/Leaflet client. Start and verification commands are maintained in
the [root README](../README.md). Set `VITE_API_BASE` and `VITE_TILE_SOURCE` as shown
in `.env.example`. Capability code lives in `src/map`, `src/categories`,
`src/detail`, and `src/progress`; Playwright tests use an isolated fixture API.
