# RDR2 P0 acceptance

Keep React/TypeScript/Leaflet, Express/SQLite, Python and the existing RDR2 map.
Preserve pan/zoom, filters, category visibility, found visibility, toggles and counts.
Add extracted local category symbols and ordered local photo galleries. Preserve
legacy data/progress with explicit backed-up migration and repeatable imports.

Acceptance requires producer/consumer validation, migration value comparisons and
rollback/backup tests, repeat/partial imports, safe formatted descriptions, gallery
identity reset and keyboard/touch controls, offline E2E, independent review, real
source evidence, desktop/mobile inspection, alignment checks and scale measurements.
Fixtures prove behavior, not extraction. Unavailable external evidence stays open.

No accounts, cloud, AI backend, stack replacement, multigame framework or deployment.
The GTA repository is read-only. Root configuration/contracts have one owner.
